# Evidence Based Everything Public Articles

このリポジトリは、Evidence Based Everything の公開可能な記事だけを読むための公開Vaultです。

## 含まれるもの

- `index.md`: Quartzなど静的サイト向けの入口
- `10_Published/`: 公開記事
- `11_Daily/`: 日次ニュース記事
- `00_Index/`: 入口・全体MOCなど、読むために必要なindexのみ
- `60_MOCs/`: 公開記事・日次記事を読むための索引
- `50_Assets/`: 公開記事・日次記事から参照される画像など、必要なassetsのみ

## 含まれないもの

- draft
- `_working/`
- `20_EvidencePackets/`
- `30_Sources/`
- `40_Claims/`
- `70_Logs/`
- Discord Bot実装
- private運用設定
- 認証情報

## 読み方

通常のGit repositoryとしてcloneまたはpullできます。

```bash
git clone <this-repository-url>
git pull
```

Obsidianで読む場合は、このフォルダをVaultとして開いてください。Quartzで公開する場合は、ルートの `index.md` を入口にしてください。
