# 概要

競輪の機械学習予測について、公開資料から比較的確実に言えることは三つある。第一に、競輪を直接対象にした研究は存在し、ニューラルネットワークやTransformerを使って着順・車券確率を予測し、予想記事や投票戦略の提示へつなげる試みがある。[1][2] 第二に、研究条件内では、確定オッズより高い回収率を示した予測器や、可読性・継続投票性を意識した買い方が報告されている。[2] 第三に、それでも「的中率が高い」「予測モデルが賢い」「長期で利益が出る」は同義ではない。[2][7]

この記事では、競輪AI予想の宣伝ではなく、公開研究と公式資料から、何がわかっていて、何がまだわかっていないかを整理する。

# この記事の見取り図

- 競輪ML予測の入力は、選手成績、番組、ライン、バンク、オッズなどである。
- 出力は、1着確率、連対確率、三連単・三連複・二連単・二連複の確率、または買い目提案になりうる。
- 評価は、分類精度や的中率だけでなく、回収率、確率校正、時系列外部検証、資金管理を分けて見る必要がある。
- 公開研究は有望な結果を示すが、独立再現、長期実運用、税・購入制約・締切時オッズを含む検証はまだ不足している。

# 定義と全体像

競輪の機械学習予測とは、過去のレース結果、選手属性・成績、レース条件、ライン、バンク特性、オッズなどを特徴量として、将来レースの着順や車券の的中確率を推定する手法である。[1][2]

競輪は自転車競技法に基づく公営競技で、地方自治体が施行者となり、経済産業省が監督官庁となる制度のもとで開催される。[3][4] 2025年3月時点の経済産業省資料では、2024年度の競輪売上は1兆3,282億円、車券発売チャネルではネット投票が84.6%を占めるとされる。[5] これは、予測モデルが直接オンライン投票・データ利用と結びつきやすい市場環境であることを意味する。ただし、市場規模が大きいことは、予測で安定して利益を出せることの根拠ではない。

競輪予測の特徴は、競馬や一般的なスポーツ勝敗予測と完全には同じでない点にある。競輪には「ライン」と呼ばれる選手間の協力関係があり、選手はレース中盤まで同じラインの選手と協力し、最後は個人として勝利を目指す。[2] そのため、選手を独立した個体としてだけ扱うモデルでは、選手間相互作用を取り落とす可能性がある。

# 歴史的背景・古典的理解

古典的な競輪予想は、競走得点、脚質、近況成績、並び、ライン、バンク特性、展開読み、人気・オッズを人間が総合する作業だった。研究文献でも、競輪の予想記事は既存記事を参考にテンプレート化できる対象として扱われており、単なる勝者予測だけでなく、初心者向けに理解可能な説明を生成する課題として位置づけられている。[1]

2018年のJ-STAGE掲載研究は、機械学習による着順予測と、予測結果を説明する予想記事生成を組み合わせた。[1] この時点で重要だったのは、「AIが当てる」ことだけではない。多数のレースについて、予想記事を人手で作るコストを下げ、初心者にも理解しやすい形で予測根拠を提示することが研究目的に含まれていた。[1]

2023年の研究会資料では、先行研究のTransformer予測器を用い、勝率、二連単、二連複、三連単、三連複の予測確率を出力し、それをボックス買いや流しといった投票戦略へ変換する手法が検討された。[2] ここで、競輪MLは「順位を予測するモデル」から「確率をもとに意思決定を支援するシステム」へ広がっている。

# 現在の標準的理解

現在の標準的な理解は、競輪ML予測を少なくとも四層に分けて考えることである。

第一層はデータである。選手の勝率・連対率・近況、番組、車番、ライン、バンク、距離、開催条件、オッズなどが候補になる。[1][2] ここで重要なのは、予測時点で入手できない情報を使わないことである。レース後に確定した情報や、締切後にしかわからないオッズを学習・評価に混ぜると、特徴量リークになる。

第二層はモデルである。公開研究ではニューラルネットワークやTransformerが使われている。[1][2] Transformer型の予測器は、選手を単体ではなくレース内の集合や順序を持つ対象として扱いやすく、ラインや選手間相互作用を表現する候補になる。ただし、Transformerであること自体が優位性を保証するわけではない。スポーツ予測ML一般では、データ分割、特徴量品質、評価設計の影響が大きい。[6]

第三層は確率評価である。競輪では「1着を当てる」だけでなく、二連単、二連複、三連単、三連複の確率を出す必要がある場合がある。[2] この場合、トップ予測の的中率だけでは不十分で、予測確率が実際の頻度と対応しているか、つまりキャリブレーションも見るべきである。

第四層は投票評価である。2023年研究会資料では、評価に2018年6月1日から2019年5月31日までの未学習データ19,757レースを使い、回収率と的中率を検証した。[2] 同資料の表では、確定オッズ三連単の回収率0.77に対し、既存三連単予測は1.05、確定オッズ二連単の0.75に対し、既存二連単予測は0.90だった。[2] ただし、これは特定研究条件でのバックテストであり、将来の実運用利益を保証しない。

# 詳細説明

## ラインと相互作用

競輪では、同じラインの選手が途中まで協力し、最終局面で競争する。[2] これは機械学習にとって、単純な「選手Aの能力値」だけでは表現しにくい構造である。ライン先頭の選手、番手の選手、三番手の選手では、同じ脚力でも勝ち筋が違う。したがって、特徴量には、個人成績だけでなく、ライン内の位置、ライン構成、地域・連携実績、バンクとの相性を入れる必要がある。

## オッズの扱い

オッズは市場参加者の情報を集約する強い特徴量である。パリミュチュエル方式では、投票額の分布によって配当が決まるため、人気やオッズには多くの人間予想と市場情報が含まれる。[2] そのため、オッズを使ったモデルは精度を上げやすい一方で、「締切時点で本当に取得できるか」「評価時に未来情報を混ぜていないか」が問題になる。

スポーツベッティングの機械学習研究でも、予測精度とベッティング収益を分けて評価する必要がある。[7] 確率予測が少し優れていても、オッズにすでに織り込まれていれば利益にはならない。逆に、的中率が低くても、過小評価された高配当を適切に選べれば回収率が上がる可能性はある。

## 的中率と回収率の違い

2023年研究会資料の結果は、この違いをよく示している。複数車券を買うボックス・流し戦略は、的中率を高めたり、長く投票を続けられるようにしたりする一方、回収率では予測確率上位の単純購入に劣る場合があった。[2] これは直感に反するが、珍しいことではない。買い目を増やせば当たりやすくなるが、購入点数も増え、期待値の低い組み合わせを含みやすくなる。

## 商用AI予想との距離

競輪AI予想サービスは多数存在するが、公開研究と同じ水準で評価されているとは限らない。注意すべき点は、検証期間、除外レース、購入金額、締切時オッズ、税、手数料、未掲載の外れ期間、資金ショート時の扱いである。これらが明示されなければ、表示された回収率は再現可能な根拠として扱いにくい。

# 応用・実践上の含意

競輪ML予測を研究・実装する場合、最低限必要な設計は次の通りである。

1. 学習・検証・テストを時系列で分ける。
2. レース前に利用できる情報だけを特徴量にする。
3. オッズありモデルとオッズなしモデルを分けて比較する。
4. 的中率、回収率、Brier scoreやlog loss、キャリブレーションを分けて報告する。
5. 購入戦略、資金配分、購入点数、締切時オッズ、除外条件を明記する。
6. 開催場、グレード、距離、ライン構成、人気帯ごとの性能を分けて見る。
7. 将来期間で再評価し、モデル劣化や市場吸収を確認する。

実務的には、最初から自動投票を目指すより、予測確率の校正と説明可能性を整えるほうが堅実である。公営競技の予測は娯楽・研究・意思決定支援としては成立しうるが、長期利益をうたうには、通常の機械学習評価よりはるかに厳しい検証が必要になる。

# 限界・論争点・未解決事項

第一の限界は、公開研究の少なさである。競輪を直接扱う研究は確認できるが、競馬やサッカーに比べると公開論文、再現コード、ベンチマークデータが少ない。[1][2][6][7]

第二の限界は、市場効率である。もしモデルの優位性が広く知られれば、同じ買い目へ投票が集まり、パリミュチュエル方式の配当は低下する。したがって、過去データで見つかった優位性は将来も残るとは限らない。[2][7]

第三の限界は、分散である。回収率が100%を超えるバックテストでも、的中の偏り、資金制約、連敗、購入上限、税務、実際の締切時オッズによって実運用の結果は変わる。[2]

第四の論点は、説明可能性である。Transformerやニューラルネットワークは複雑な相互作用を捉えられる可能性があるが、予測根拠が人間に理解しにくい。競輪ではラインや展開読みが重要なため、単に確率を出すだけでなく、どの条件が予測に効いたのかを説明する設計が求められる。[1][2]

第五の未解決事項は、個人に対する責任ある提示である。予測システムが娯楽性を高めることと、過度な投票を促すことは紙一重である。公営競技の制度的背景を踏まえると、AI予測の表示には、リスク、限界、損失可能性を明確に示す必要がある。[3][4]

# まとめ

競輪の機械学習予測については、ニューラルネットワークやTransformerを用いた着順・車券確率予測、予想記事生成、投票戦略提示の公開研究がある。[1][2] 研究条件内では、確定オッズより高い回収率を示した予測器も報告されている。[2] しかし、公開研究はまだ少なく、独立再現、将来期間での外部検証、実運用の取引条件、税・資金管理まで含めた利益検証は不足している。

結論として、競輪ML予測は「可能性のある研究対象」ではあるが、「AIなら安定して勝てる」とは言えない。最も信頼できる読み方は、的中率、確率校正、回収率、分散、外部検証を分け、モデルの優位性が市場に吸収される可能性を常に考慮することである。
